# وب‌سایت ساری چین

رابط وب‌سایت با Next.js App Router و React ساخته شده است. برای اجرا به Node.js نسخه ۲۰٫۹ یا بالاتر نیاز است.

```bash
npm ci
npm run dev
```

نشانی پیش‌فرض توسعه `http://localhost:3000` است.

```bash
npm run build
npm start
```

مسیرهای فعلی شامل صفحه اصلی، `/categories`، `/quick-order`، `/login` و `/register` هستند. کاتالوگ، ثبت درخواست سفارش مستقیم و حساب همکار به API بک‌اند در مسیر `/web` متصل‌اند. صفحهٔ محصول فقط اطلاعات ثبت‌شده در کاتالوگ را نمایش می‌دهد.

## دفترچه مواد اولیه

مسیر `/suppliers` به API واقعی متصل است و پس از ورود با حساب ذخیره‌شده در بک‌اند، اطلاعات تماس منتشرشده را نمایش می‌دهد. نشانی بک‌اند را در محیط سرور Next.js با `BACKEND_URL` تنظیم کنید. پیش‌فرض توسعه `http://127.0.0.1:3001` است.

## فروشندگان و همکاران

در `/partners` اعضای دارای رمز تعیین‌شده در پنل، پروفایل خریدار، تولیدکننده یا ارائه‌دهنده خدمات را در یک حساب تکمیل می‌کنند. وضعیت مجوز در همان صفحه نمایش داده می‌شود. نشانی بک‌اند را با `BACKEND_URL` در محیط سرور Next.js تنظیم کنید.

### دسترسی از شبکهٔ محلی

برای اجرای سایت روی شبکه بدون WebSocket مربوط به توسعه، نسخهٔ build شده را اجرا کنید.

```bash
npm run build
npm start -- --hostname 0.0.0.0
```

اگر به به‌روزرسانی خودکار حین توسعه نیاز دارید، نام میزبان یا IP مورد اعتماد را
در `NEXT_DEV_ALLOWED_HOSTS` قرار دهید. مقدار باید فقط نام میزبان باشد. برای چند
میزبان از ویرگول استفاده کنید.

```bash
NEXT_DEV_ALLOWED_HOSTS=192.168.1.161 npm run dev -- --hostname 0.0.0.0
```

حساب‌های نمونهٔ همکار با رمز کوتاه فقط وقتی فعال‌اند که بک‌اند توسعه با
`SEED_MARKETPLACE_DEMO=true` و خارج از حالت `NODE_ENV=production` اجرا شود.
اجرای نسخهٔ build شدهٔ سایت، تنظیمات فرایند جداگانهٔ بک‌اند را تغییر نمی‌دهد.

پنل `/partners` داشبورد، ویرایش پروفایل و فهرست سفارش‌های جاری را نمایش می‌دهد.
رکوردهای محصول، باغ، حمل‌ونقل و مشاوره در حساب عضو ذخیره می‌شوند.
آگهی‌های بولتن حمل‌ونقل برای اعضای واردشده قابل مشاهده‌اند.

قیمت کاتالوگ از بازهٔ `price.min` و `price.max` بر حسب کارسا خوانده می‌شود. محصول بی‌قیمت با صفر نمایش داده می‌شود. فیلتر قیمت، بازه‌های هم‌پوشان را نشان می‌دهد.
