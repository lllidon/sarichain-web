# وب‌سایت ساری چین

رابط وب‌سایت با Next.js App Router و React ساخته شده است. برای اجرا به Node.js نسخه ۲۰٫۹ یا بالاتر نیاز است.

```bash
npm ci
npm run dev
```

نشانی پیش‌فرض توسعه `http://localhost:3000` است.

```bash
npm run build
npm start
```

مسیرهای فعلی شامل صفحه اصلی، `/categories`، `/quick-order`، `/login` و `/register` هستند. کاتالوگ، سفارش و حساب کاربری همچنان با داده و منطق نمونه در مرورگر کار می‌کنند.
